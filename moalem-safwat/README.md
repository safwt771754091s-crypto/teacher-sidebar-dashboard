# المعلّم صفوت — Safwat Smart Teacher

واجهة تعليمية عربية RTL متجاوبة، مهيأة للويب والتغليف كتطبيق Android عبر Capacitor.

## الحالة الحالية
- تم إنشاء هيكل تطبيق مستقل داخل هذا المجلد مع تسجيل دخول Supabase، ملف الطالب، جدول الحصص، واجهة سؤال المعلّم، وألعاب رياضيات وإنجليزية.
- الألعاب الحالية أنشطة تدريبية عامة وليست منسوبة إلى كتب مدرسية.
- محتوى المنهج وخدمة الذكاء الاصطناعي غير مفعّلين حتى يتم استيراد الكتب ومراجعتها ونشر وظيفة الخادم.
- لا توجد بيانات طلاب وهمية مزروعة في قاعدة البيانات.
- **لم يتم ربط أي مشروع Supabase حتى الآن.** لا تستخدم مشروع الفائق يمن.

## إعداد Supabase
1. أنشئ مشروعًا مستقلًا باسم `moalem-safwat` في المؤسسة المناسبة، بعد مراجعة التكلفة والخطة.
2. من SQL Editor أو Supabase CLI، طبّق `supabase/migrations/202610140001_initial.sql` على المشروع الجديد فقط.
3. في إعدادات Auth، اضبط عناوين الموقع وإعادة التوجيه، وفعّل تأكيد البريد بحسب سياسة التشغيل.
4. انسخ `.env.example` إلى `.env.local` وضع `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` (أو publishable key). لا تستخدم service_role في تطبيق الويب أو Android.
5. أنشئ وظيفة Edge Function باسم `student-tutor` تستدعي مزوّد الذكاء الاصطناعي من الخادم فقط، وتتحقق من جلسة المستخدم ومعدلات الاستخدام، وتسترجع محتوى الكتب المعتمد مع المصادر.
6. لا تستورد كتبًا أو تنشر دروسًا قبل التحقق من المصدر والطبعة وحقوق الاستخدام ومراجعة النص المستخرج.

## التشغيل محليًا
```sh
npm install
cp .env.example .env.local
npm run dev
``

التحقق من البناء:
```sh
npm run build
``

## Android
يتطلب Android build بيئة Java/Android SDK. لإنشاء مشروع Android محليًا:
```sh
npm run android:init
npm run android:sync
cd android && ./gradlew assembleDebug
``

Workflow GitHub Actions سيحاول إنشاء APK تجريبي من نفس المصدر وإرفاقه كـ artifact؛ نجاحه لا يعني أن التطبيق منشور على متجر Google Play.

## الخصوصية والأمان
- سياسات RLS تقيد ملفات الطلاب والجداول ومحاولات التعلم بصاحب الحساب.
- المحتوى الدراسي للقراءة فقط للطالب عند اعتماده ونشره.
- لا توجد سياسة تسمح للمتصفح بكتابة محتوى المنهج أو اعتماده.
- لا تضع مفاتيح سرية أو بيانات طلاب حقيقية في GitHub.
